## Portfolio project rules

- Read `PROJECT_GUIDE.md` before planning or editing this project.
- This is a standalone public portfolio, not part of the reliable-properties application or any dashboard.
- Do not invent personal history, employers, testimonials, awards, project outcomes, or contact details. Use clearly marked placeholders until source content is supplied.
- Server Components are the default. Client Components require a concrete interaction.
- Motion must be purposeful, performant, interruptible where appropriate, and compatible with `prefers-reduced-motion`.
- Before changing Next.js behavior, read the relevant installed guide under `node_modules/next/dist/docs/`.
- Before design or animation work, read the relevant local skill under `.agents/skills/` completely.
- Run `npm run lint`, `npm run typecheck`, and `npm run build` before handoff.
