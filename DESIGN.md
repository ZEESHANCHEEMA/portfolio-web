# Design System

## Thesis

Zeeshan’s identity leads and verified work supports it. The portfolio rejects competing dashboard zones, device collages, floating technology logos, and unsupported metrics.

## Visual world

The material language is a dark product studio: near-black space, mineral-white typography, restrained graphite rules, and one electric-periwinkle signal color. Project work appears as large, singular browser specimens rather than small cards or mixed device mockups.

## Typography

Geist Sans is the primary face and Geist Mono is reserved for measurements, platform labels, dates, and technical data. Display text is dense and direct with restrained negative tracking; body copy stays readable and neutral.

## Color

- Background: `#0b0c0e`
- Foreground: `#f2f2ec`
- Muted bright: `#aaadb4`
- Muted: `#74777f`
- Muted dark: `#454850`
- Border: `#25272c`
- Accent: `#818cf8`

Color is used in committed fields and meaningful states, not sprinkled decoration. Text contrast must remain WCAG AA.

## Composition

The introduction owns the first viewport with oversized type and generous negative space. Project evidence begins below the fold so the visitor receives one idea at a time. Desktop and mobile use the same narrative order rather than separate compositions.

## Components

Navigation is a quiet top rail. Primary actions use the periwinkle signal color with precise press feedback; secondary actions use a graphite outline. Project presentations are full-width browser specimens. Mobile phone frames are not part of this system.

## Motion

Motion is concentrated into one branded load sequence followed by one coordinated content reveal. Motion for React powers the transition; direct UI feedback remains below 250ms. Reduced-motion users bypass the loader and receive content immediately.

## Responsive behavior

The workbench retains its hierarchy rather than shrinking proportionally. On narrow screens, controls become horizontally scrollable, device layers reduce overlap, and nonessential measurement annotations disappear. Interactive targets remain at least 44px.
